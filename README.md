# Happy Birthday Koko 💜

A little interactive birthday surprise (in Japanese), hosted on GitHub Pages:
https://shoon-lae-yee-win.github.io/happy_birthday/

**Flow:** passcode → light & blow out the candle → gift (💜 + 💌) → Japanese letter → a question → heart-catch mini game → "永遠の愛" → "愛してる" → Happy Birthday finale.

## Customize
Open `index.html` and edit the `CONFIG` block near the bottom:

- `name`, `from` – names
- `passcode` and `passcodeHint`
- `letter`, `question`, `loveMessage`, ... – all the text
- `heartsToCatch` – how many hearts to tap in the mini game
- `photos` – put pictures in `images/` and list them, e.g. `["images/1.jpg", "images/2.jpg"]`
- `music` – put a song in `music/` and set e.g. `"music/song.mp3"`

Commit and push; GitHub Pages updates in about a minute.
