# Happy Birthday 🎂

A little interactive birthday surprise, hosted on GitHub Pages.

**Flow:** passcode → light & blow out the candle → gift → letter → a question → balloon-shooting game → "Eternal Love" → "I Love You" → Happy Birthday finale.

## Customize
Open `index.html` and edit the `CONFIG` block near the bottom:

- `name`, `from` – names
- `passcode` – 4-digit code (default `1104`) and `passcodeHint`
- `letter`, `question`, `loveMessage`, ... – all the text
- `photos` – put pictures in `images/` and list them, e.g. `["images/1.jpg", "images/2.jpg"]`
- `music` – put a song in `music/` and set e.g. `"music/song.mp3"`

Commit and push; GitHub Pages updates in about a minute.
